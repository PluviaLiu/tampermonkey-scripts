# Tampermonkey Scripts

一些自己编写或整理的 Tampermonkey 脚本。

## 脚本列表

### Bilibili MP3 Downloader

在哔哩哔哩网页，添加一个按键，直接下载其视频的MP3。

### GitHub Hide Follower Number

隐藏 GitHub 个人主页上的粉丝数量。

### BB File Downloader

用于一键下载Blackboard上的课程资料。
作者：[Jesperro](https://github.com/Jesperro) 

## 使用方法

1. 安装 [Tampermonkey](https://www.tampermonkey.net/)。
2. 新建脚本文件，复制我的脚本内容，保存即可使用。
